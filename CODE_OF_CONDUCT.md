# Code of Conduct

Mindmory contributors are expected to communicate respectfully, welcome
constructive disagreement, and focus criticism on ideas and code rather than
people. Harassment, discrimination, threats, publication of private
information, and other abusive behavior are not acceptable.

Project maintainers may edit or remove contributions and restrict participation
when necessary to protect a safe, productive community. Conduct concerns should
be reported privately through the repository's maintainer or security contact.
