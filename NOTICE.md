Prebuilt Mindmory binaries incorporate third-party open-source Go modules.
`THIRD_PARTY_NOTICES.md` identifies the compiled module inventory, and
`THIRD_PARTY_LICENSES.txt` contains the complete upstream license and notice
files. Retain both files with redistributed binaries.

The project draws on general memory-system concepts such as provenance,
evidence-aware retrieval, lifecycle governance, and derived indexes. The
repository does not include AgentOS runtime packages.
